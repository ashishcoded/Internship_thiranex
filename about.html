About me

Developer focused on useful, inclusive web experiences.

I enjoy turning ideas into simple interfaces that are structured, responsive and easy to use.

My approach

I start with HTML that describes the meaning of the content. Then I use CSS for presentation and JavaScript only when interaction needs it.

This approach keeps websites understandable, progressively enhanced and easier to maintain.

Development principles

  • Semantic-first markup
  • Keyboard accessibility
  • Responsive by default
  • Performance-conscious assets
  • Clear content hierarchy

Skills

HTML5

Semantic structure, forms and accessible landmarks.

CSS3

Flexbox, Grid, responsive design and modern layouts.

JavaScript

DOM manipulation, events and client-side interactions.

Accessibility

WCAG-aware patterns, keyboard support and screen-reader-friendly content.
